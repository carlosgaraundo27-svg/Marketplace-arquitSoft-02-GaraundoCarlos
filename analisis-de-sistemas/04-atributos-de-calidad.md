# Atributos de Calidad

| ID | Atributo de Calidad | Escenario de Calidad |
| :--- | :--- | :--- |
| **AC01** | **Rendimiento** | Las consultas de productos y operaciones del carrito deben responder con latencias bajas (< 1 segundo), incluso ante concurrencia masiva en campañas comerciales. |
| **AC02** | **Disponibilidad** | El sistema debe permanecer disponible y operativo de manera continua durante los periodos de alta demanda promocional. |
| **AC03** | **Escalabilidad** | El sistema debe soportar un incremento sustancial en el volumen de usuarios y peticiones concurrentes sin degradar sus transacciones. |
| **AC04** | **Seguridad** | Los datos personales de los usuarios, credenciales y transacciones financieras deben estar protegidos contra accesos no autorizados mediante cifrado. |
| **AC05** | **Mantenibilidad** | El sistema debe mantener una separación modular clara que permita actualizar o corregir componentes sin alterar el resto de la plataforma. |
