# Identificación de Actores del Sistema

## 1. Actores Humanos

| Actor | Descripción / Responsabilidades |
| :--- | :--- |
| **Cliente** | Persona que busca productos, consulta información, gestiona el carrito de compras, efectúa el pago y consulta el estado de sus pedidos. |
| **Seller** | Comercio o vendedor independiente que ofrece productos, registra y actualiza su catálogo/stock y gestiona las ventas realizadas. |
| **Administrador** | Responsable de gestionar la plataforma, habilitar o suspender sellers y supervisar el funcionamiento del sistema. |

## 2. Sistemas Externos

| Sistema Externo | Responsabilidad Técnica |
| :--- | :--- |
| **Pasarela de pago** | Procesar de forma segura las transacciones bancarias, pagos con tarjetas y billeteras electrónicas. |
| **Servicio de envío** | Gestionar y calcular la información logística, costos de despacho y tracking de entrega. |
| **Servicio de Facturación** | Generar comprobantes electrónicos de pago (boletas/facturas) conforme a la normativa fiscal. |
| **ERP** | Proporcionar e integrar la sincronización de inventarios, productos y datos contables existentes. |
